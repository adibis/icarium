# CDC-001: Unsynchronized control crossing

**Severity:** error

The destination flop has no follow-on synchronizer in its own
clock: a single-bit signal lands and is used directly, with no
second stage to filter metastability. Add a 2FF chain, or assert
(* cdc_sync *) on a vetted synchronizer, (* cdc_static *) on a
source held constant, (* cdc_handshake *) on a capture register.

## Suppression marks

This rule honors: `(* cdc_static *)`, `(* cdc_sync *)`, `(* cdc_handshake *)`.

## Failing example

`fixtures/CDC-001/bad_sync_missing.sv`:

```systemverilog
module bad_sync_missing (
    input  logic ca,
    input  logic cb,
    input  logic d,
    output logic q
);
  logic src_q, dst_q;

  always_ff @(posedge ca) src_q <= d;
  always_ff @(posedge cb) dst_q <= src_q;
  assign q = dst_q;
endmodule
```

with `fixtures/CDC-001/bad_sync_missing.sdc`:

```tcl
create_clock -name ca -period 10 [get_ports ca]
create_clock -name cb -period 7 [get_ports cb]
set_clock_groups -asynchronous -group {ca} -group {cb}
set_input_delay -clock ca 1.0 [get_ports d]
```
