# CDC-004: Multi-bit bus crossing without gating or gray-coding

**Severity:** error

A multi-bit path crosses domains with no coherence mechanism:
lanes settle on different cycles, so the destination can sample
a value never sent. Gate the bus behind a synchronized enable,
gray-code it into a multi-bit chain, or assert the promise.

## Suppression marks

This rule honors: `(* cdc_gray *)`, `(* cdc_static *)`.

## Failing example

`fixtures/CDC-004/bad_bare_bus.sv`:

```systemverilog
module bad_bare_bus (
    input  logic ca,
    input  logic cb,
    input  logic [3:0] d,
    output logic [3:0] q
);
  logic [3:0] src_q, dst_q;

  always_ff @(posedge ca) src_q <= d;
  always_ff @(posedge cb) dst_q <= src_q;
  assign q = dst_q;
endmodule
```

with `fixtures/CDC-004/bad_bare_bus.sdc`:

```tcl
create_clock -name ca -period 10 [get_ports ca]
create_clock -name cb -period 7 [get_ports cb]
set_clock_groups -asynchronous -group {ca} -group {cb}
set_input_delay -clock ca 1.0 [get_ports d]
```

More failing cases: `bad_port_bus.sv`.
