---
title: "RDC-001: Async reset released from a foreign clock domain"
linkTitle: "RDC-001 Async reset released from a foreign clock domain"
weight: 125
---

**Severity:** error

A flop's async reset fans in from a register in another clock
domain: every foreign deassertion races the local clock, so
the flop never reaches a clean out-of-reset state. Reset it
from its own domain's tree, or synchronize the reset across.

## Failing example

`fixtures/RDC-001/bad_foreign_release.sv`:

```systemverilog
// RDC-001: a 2FF chain in dst_clk whose ARST comes from a flop
// registered in src_clk. CDC-015 frames the chain side; RDC-001
// frames the reset-release side. Both fire by design.
// RDC-009 stays silent: the foreign reset still releases after
// the shared global root, so source data settles first.
// RDC-010 frames the reset side as a single-flop chain serving
// a foreign clock: chain-clock errors plus the record note.
module bad_foreign_release (
    input  logic src_clk,
    input  logic dst_clk,
    input  logic global_rst_n,
    input  logic async_signal,
    output logic dst_q
);

    logic src_rst_q;
    always_ff @(posedge src_clk or negedge global_rst_n) begin
        if (!global_rst_n) src_rst_q <= 1'b0;
        else               src_rst_q <= 1'b1;
    end

    logic src_q;
    always_ff @(posedge src_clk or negedge global_rst_n) begin
        if (!global_rst_n) src_q <= 1'b0;
        else               src_q <= async_signal;
    end

    logic sync_1;
    always_ff @(posedge dst_clk or negedge src_rst_q) begin
        if (!src_rst_q) sync_1 <= 1'b0;
        else            sync_1 <= src_q;
    end

    logic sync_2;
    always_ff @(posedge dst_clk or negedge src_rst_q) begin
        if (!src_rst_q) sync_2 <= 1'b0;
        else            sync_2 <= sync_1;
    end

    assign dst_q = sync_2;

endmodule
```

with `fixtures/RDC-001/bad_foreign_release.sdc`:

```tcl
create_clock -name src_clk -period 10.0 [get_ports src_clk]
create_clock -name dst_clk -period 7.5  [get_ports dst_clk]
set_clock_groups -asynchronous -group {src_clk} -group {dst_clk}
set_input_delay -clock src_clk 1.0 [get_ports async_signal]
```
