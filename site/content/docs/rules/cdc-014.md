---
title: "CDC-014: Combinational logic between synchronizer stages"
linkTitle: "CDC-014 Combinational logic between synchronizer stages"
weight: 112
---

**Severity:** error

A gate sits between two stages of a synchronizer: its delay
eats into the resolution time the chain was meant to provide,
and it can pass a metastable or glitching value on to the
next stage. Move the gate past the chain's final stage.

## Suppression marks

This rule honors: `(* cdc_sync *)`, `(* cdc_handshake *)`.

## Failing example

`fixtures/CDC-014/bad_gate_between.sv`:

```systemverilog
// CDC-014: an AND gate sits between the two synchronizer stages.
// Depth reads 1, but a second stage exists behind the gate, so
// CDC-001 defers and CDC-014 fires with the correct framing.
module bad_gate_between (
    input  logic src_clk,
    input  logic dst_clk,
    input  logic rst_n,
    input  logic d_in,
    input  logic mask_in,
    output logic q_out
);

    logic src_q;
    always_ff @(posedge src_clk or negedge rst_n) begin
        if (!rst_n) src_q <= 1'b0;
        else        src_q <= d_in;
    end

    logic mask_q;
    always_ff @(posedge dst_clk or negedge rst_n) begin
        if (!rst_n) mask_q <= 1'b1;
        else        mask_q <= mask_in;
    end

    logic sync_1;
    always_ff @(posedge dst_clk or negedge rst_n) begin
        if (!rst_n) sync_1 <= 1'b0;
        else        sync_1 <= src_q;
    end

    logic sync_2;
    always_ff @(posedge dst_clk or negedge rst_n) begin
        if (!rst_n) sync_2 <= 1'b0;
        else        sync_2 <= sync_1 & mask_q;
    end

    assign q_out = sync_2;

endmodule
```

with `fixtures/CDC-014/bad_gate_between.sdc`:

```tcl
create_clock -name src_clk -period 10.0 [get_ports src_clk]
create_clock -name dst_clk -period 7.5  [get_ports dst_clk]
set_clock_groups -asynchronous -group {src_clk} -group {dst_clk}
set_input_delay -clock src_clk 1.0 [get_ports d_in]
set_input_delay -clock dst_clk 1.0 [get_ports mask_in]
```
