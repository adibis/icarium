---
title: "RDC-007: Reset synchronizer chain loads the asserted value"
linkTitle: RDC-007
weight: 131
---

**Severity:** error

A reset synchronizer chain whose head D ties to the asserted
value never deasserts: on release it reloads assertion and
holds every downstream consumer in reset forever. Tie the
head D to the deasserted value: 1'b1 for active-low resets.

## Failing example

`fixtures/RDC-007/bad_chain_deassert_polarity.sv`:

```systemverilog
// RDC-007: an active-low reset chain whose head loads 1'b0,
// the asserted value, instead of 1'b1. Structurally a fine
// chain otherwise, so recognition accepts it; the tail then
// holds downstream consumers in reset forever.
module bad_chain_deassert_polarity (
    input  logic dst_clk,
    input  logic raw_rst_n,
    output logic rst_n_sync
);

    logic meta;
    always_ff @(posedge dst_clk or negedge raw_rst_n) begin
        if (!raw_rst_n) meta <= 1'b0;
        else            meta <= 1'b0;
    end
    always_ff @(posedge dst_clk or negedge raw_rst_n) begin
        if (!raw_rst_n) rst_n_sync <= 1'b0;
        else            rst_n_sync <= meta;
    end

endmodule
```

with `fixtures/RDC-007/bad_chain_deassert_polarity.sdc`:

```tcl
create_clock -name dst_clk -period 10.0 [get_ports dst_clk]
```
