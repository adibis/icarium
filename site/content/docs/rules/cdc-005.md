---
title: "CDC-005: Reconvergent synchronizers"
linkTitle: CDC-005
weight: 104
---

**Severity:** warning

One source flop fans out to independent synchronizer chains
whose outputs recombine downstream: each chain resolves
metastability on its own cycle, so the recombination can see
a value pair never true at the source. Synchronize once and
fan out after, or prove the skew harmless.

## Failing example

`fixtures/CDC-005/bad_reconvergent.sv`:

```systemverilog
// Reconvergent twin chains: CDC-005 proves the recombination and
// CDC-024 flags the fanout behind it. Both fire by design.
module bad_reconvergent (
    input  logic ca,
    input  logic cb,
    input  logic d,
    output logic q
);
  logic src_q, a1_q, a2_q, b1_q, b2_q, c_q;

  always_ff @(posedge ca) src_q <= d;
  always_ff @(posedge cb) a1_q <= src_q;
  always_ff @(posedge cb) a2_q <= a1_q;
  always_ff @(posedge cb) b1_q <= src_q;
  always_ff @(posedge cb) b2_q <= b1_q;
  always_ff @(posedge cb) c_q <= a2_q & b2_q;
  assign q = c_q;
endmodule
```

with `fixtures/CDC-005/bad_reconvergent.sdc`:

```tcl
create_clock -name ca -period 10 [get_ports ca]
create_clock -name cb -period 7 [get_ports cb]
set_clock_groups -asynchronous -group {ca} -group {cb}
set_input_delay -clock ca 1.0 [get_ports d]
```
