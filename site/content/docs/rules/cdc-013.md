---
title: "CDC-013: Toggle-synchronizer event loss on fast-to-slow crossing"
linkTitle: "CDC-013 Toggle-synchronizer event loss on fast-to-slow crossing"
weight: 111
---

**Severity:** warning

A toggling source runs fast to slow past the period ratio:
two toggles between destination samples cancel to zero edges
and both events are silently lost. A handshake or
backpressure closes it. An XOR tail does not: it turns each
toggle into a pulse, but cancelled toggles never reach it.
A toggle whose enable waits on its own acknowledgement, the
destination's synchronized toggle returned through a 2FF
chain, never toggles twice between samples and is silent.

## Suppression marks

This rule honors: `(* cdc_handshake *)`.

## Failing example

`fixtures/CDC-013/bad_toggle_bare.sv`:

```systemverilog
// CDC-013: a fast toggle source into a 2FF chain with no XOR
// tail. The chain output tracks the toggle level, so two fast
// toggles between slow samples vanish without a trace.
module bad_toggle_bare (
    input  logic src_clk,
    input  logic dst_clk,
    input  logic rst_n,
    input  logic event_in,
    output logic event_seen
);

    logic src_toggle;
    always_ff @(posedge src_clk or negedge rst_n) begin
        if (!rst_n)        src_toggle <= 1'b0;
        else if (event_in) src_toggle <= ~src_toggle;
    end

    logic toggle_meta;
    logic toggle_sync;
    always_ff @(posedge dst_clk or negedge rst_n) begin
        if (!rst_n) begin
            toggle_meta <= 1'b0;
            toggle_sync <= 1'b0;
        end else begin
            toggle_meta <= src_toggle;
            toggle_sync <= toggle_meta;
        end
    end

    assign event_seen = toggle_sync;

endmodule
```

with `fixtures/CDC-013/bad_toggle_bare.sdc`:

```tcl
create_clock -name src_clk -period 2.0  [get_ports src_clk]
create_clock -name dst_clk -period 20.0 [get_ports dst_clk]
set_clock_groups -asynchronous -group {src_clk} -group {dst_clk}
set_input_delay -clock src_clk 0.5 [get_ports event_in]
```

More failing cases: `bad_toggle_foreign_ack.sv`, `bad_xor_tail.sv`.
