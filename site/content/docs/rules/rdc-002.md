---
title: "RDC-002: Reset polarity mismatch on async reset distribution"
linkTitle: RDC-002
weight: 126
---

**Severity:** error

A flop's async reset disagrees with its source: a producer
flop drives a value the consumer never treats as assert, or a
port declaration contradicts the pin. The consumer never
enters reset when the source does. Add an inverter, or fix
the edge to match the declaration.

## Suppression marks

This rule honors: `(* reset_sync *)`.

## Failing example

`fixtures/RDC-002/bad_flop_mismatch.sv`:

```systemverilog
// RDC-002: single clock, no CDC crossing at all. The producer
// flop wakes from reset driving 0, but the consumer's ARST pin
// asserts on 1: the consumer never enters reset with the system.
module bad_flop_mismatch (
    input  logic clk,
    input  logic raw_rst_n,
    output logic q_out
);

    logic gated_rst;
    always_ff @(posedge clk or negedge raw_rst_n) begin
        if (!raw_rst_n) gated_rst <= 1'b0;
        else            gated_rst <= 1'b1;
    end

    always_ff @(posedge clk or posedge gated_rst) begin
        if (gated_rst) q_out <= 1'b0;
        else           q_out <= 1'b1;
    end

endmodule
```

with `fixtures/RDC-002/bad_flop_mismatch.sdc`:

```tcl
create_clock -name clk -period 10.0 [get_ports clk]
set_input_delay -clock clk 1.0 [get_ports raw_rst_n]
```

More failing cases: `bad_port_declared.sv`.
