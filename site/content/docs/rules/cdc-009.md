**Severity:** warning

A single-bit flop crossing runs fast to slow (source period
times 1.5 below the destination period) and the source flop
is an edge detector: a 1-cycle pulse may slip between slow
edges. Stretch the pulse, toggle it, or handshake it.

## Failing example

`fixtures/CDC-009/bad_fast_pulse.sv`:

```systemverilog
module bad_fast_pulse (
    input  logic fc,
    input  logic sc,
    input  logic stim,
    output logic q
);
  logic req_q, req_d, pulse_q, s1_q, s2_q;

  always_ff @(posedge fc) req_q <= stim;
  always_ff @(posedge fc) req_d <= req_q;
  always_ff @(posedge fc) pulse_q <= req_q & ~req_d;
  always_ff @(posedge sc) s1_q <= pulse_q;
  always_ff @(posedge sc) s2_q <= s1_q;
  assign q = s2_q;
endmodule
```

with `fixtures/CDC-009/bad_fast_pulse.sdc`:

```tcl
create_clock -name fc -period 4 [get_ports fc]
create_clock -name sc -period 10 [get_ports sc]
set_clock_groups -asynchronous -group {fc} -group {sc}
set_input_delay -clock fc 1.0 [get_ports stim]
```
