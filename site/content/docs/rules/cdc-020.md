---
title: "CDC-020: Sliced-bus reconvergence across CDC"
linkTitle: CDC-020
weight: 118
---

**Severity:** warning

A multi-bit source register fans lane by lane to two or more
destinations in one domain: each lane resolves apart, so the
destination can sample mixes the source never emits. Gray-code
the source, handshake it, or sync the bus whole.

## Suppression marks

This rule honors: `(* cdc_gray *)`, `(* cdc_static *)`, `(* cdc_handshake *)`.

## Failing example

`fixtures/CDC-020/bad_sliced_bus.sv`:

```systemverilog
// CDC-020: a true 4-bit register sliced into wires, each lane
// 2FF-synced apart and recombined. Every crossing is width 1,
// so CDC-004 misses the bus the lanes still form together.
module bad_sliced_bus (
    input  logic       src_clk,
    input  logic       dst_clk,
    input  logic [3:0] d_in,
    output logic [3:0] data_dst
);

    logic [3:0] data;
    always_ff @(posedge src_clk) data <= d_in;

    logic d0, d1, d2, d3;
    assign d0 = data[0];
    assign d1 = data[1];
    assign d2 = data[2];
    assign d3 = data[3];

    logic d0_m, d0_s, d1_m, d1_s, d2_m, d2_s, d3_m, d3_s;
    always_ff @(posedge dst_clk) begin
        d0_m <= d0; d0_s <= d0_m;
        d1_m <= d1; d1_s <= d1_m;
        d2_m <= d2; d2_s <= d2_m;
        d3_m <= d3; d3_s <= d3_m;
    end

    assign data_dst = {d3_s, d2_s, d1_s, d0_s};

endmodule
```

with `fixtures/CDC-020/bad_sliced_bus.sdc`:

```tcl
create_clock -name src_clk -period 10.0 [get_ports src_clk]
create_clock -name dst_clk -period 7.5  [get_ports dst_clk]
set_clock_groups -asynchronous -group {src_clk} -group {dst_clk}
set_input_delay -clock src_clk 1.0 [get_ports d_in]
```
