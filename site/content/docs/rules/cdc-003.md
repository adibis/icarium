# CDC-003: Combinational logic on the way to a synchronizer

**Severity:** error

Source-domain signals combine through a gate before the
synchronizer: the gate can glitch across source cycles and a
2FF cannot filter the transient. Synchronize each source bit
first, then combine in the destination domain.

## Suppression marks

This rule honors: `(* cdc_static *)`, `(* cdc_sync *)`.

## Failing example

`fixtures/CDC-003/bad_comb_before_sync.sv`:

```systemverilog
module bad_comb_before_sync (
    input  logic ca,
    input  logic cb,
    input  logic d1,
    input  logic d2,
    output logic q
);
  logic p_q, r_q, s1_q, s2_q;

  always_ff @(posedge ca) p_q <= d1;
  always_ff @(posedge ca) r_q <= d2;
  always_ff @(posedge cb) s1_q <= p_q & r_q;
  always_ff @(posedge cb) s2_q <= s1_q;
  assign q = s2_q;
endmodule
```

with `fixtures/CDC-003/bad_comb_before_sync.sdc`:

```tcl
create_clock -name ca -period 10 [get_ports ca]
create_clock -name cb -period 7 [get_ports cb]
set_clock_groups -asynchronous -group {ca} -group {cb}
set_input_delay -clock ca 1.0 [get_ports d1]
set_input_delay -clock ca 1.0 [get_ports d2]
```

## Passing examples

- `good_direct_sync.sv` — clean (direct sync)
