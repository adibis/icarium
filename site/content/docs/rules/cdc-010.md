---
title: "CDC-010: Clock mux or gate control that can emit a runt pulse"
linkTitle: "CDC-010 Clock mux or gate control that can emit a runt pulse"
weight: 108
---

**Severity:** error

A clock mux select or gate enable can chop the output clock
into runt pulses no sink synchronizer can heal. Two shapes
fire. A control driven from a domain async to every clock the
cell gates. And a plain mux switching between asynchronous
clocks, whatever domain its select comes from: a select
synchronous to one leg still lands mid-phase on the other.
Use a glitch-free (break-before-make) mux, or mark the select
cdc_static if it only changes while the clocks are stopped.

## Suppression marks

This rule honors: `(* cdc_static *)`.

## Failing example

`fixtures/CDC-010/bad_async_mux_select.sv`:

```systemverilog
module bad_async_mux_select (
    input  logic ca,
    input  logic cb,
    input  logic cc,
    input  logic en_d,
    input  logic d,
    output logic q
);
  logic en_q, gclk, src_q, f_q, s_q;

  always_ff @(posedge cc) en_q <= en_d;
  assign gclk = en_q ? ca : cb;
  always_ff @(posedge ca) src_q <= d;
  always_ff @(posedge gclk) f_q <= src_q;
  always_ff @(posedge gclk) s_q <= f_q;
  assign q = s_q;
endmodule
```

with `fixtures/CDC-010/bad_async_mux_select.sdc`:

```tcl
create_clock -name ca -period 10 [get_ports ca]
create_clock -name cb -period 7 [get_ports cb]
create_clock -name cc -period 11 [get_ports cc]
set_clock_groups -asynchronous -group {ca} -group {cb} -group {cc}
set_input_delay -clock cc 1.0 [get_ports en_d]
set_input_delay -clock ca 1.0 [get_ports d]
```

More failing cases: `bad_shared_clock_select.sv`, `bad_shared_port_select.sv`.

## Passing examples

- `good_static_select.sv` — clean (static select)
