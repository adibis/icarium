---
title: "RDC-008: Primary reset port unsynchronized in one domain"
linkTitle: "RDC-008 Primary reset port unsynchronized in one domain"
weight: 132
---

**Severity:** error

A top-level reset port fans straight into flops of a domain
with no reset synchronizer, while another domain syncs the
same port: the builder knew, then missed a domain. Sync the
port in every consuming domain. Silent when every domain
uses the raw port; that simplification is a separate review.

## Suppression marks

This rule honors: `(* reset_sync *)`.

## Failing example

`fixtures/RDC-008/bad_reset_port_missed_domain.sv`:

```systemverilog
// RDC-008: raw_rst_n has a proper chain in clk_a, proving the
// builder knows the port needs syncing, but two clk_b flops
// take the raw port with no chain in their domain. The miss,
// not the raw port alone, is the finding.
module bad_reset_port_missed_domain (
    input  logic clk_a,
    input  logic clk_b,
    input  logic raw_rst_n,
    input  logic d_in_a,
    input  logic d_in_b,
    output logic q_a,
    output logic q_b
);

    logic rst_a_meta, rst_a_n;
    always_ff @(posedge clk_a or negedge raw_rst_n)
        if (!raw_rst_n) rst_a_meta <= 1'b0;
        else            rst_a_meta <= 1'b1;
    always_ff @(posedge clk_a or negedge raw_rst_n)
        if (!raw_rst_n) rst_a_n <= 1'b0;
        else            rst_a_n <= rst_a_meta;

    always_ff @(posedge clk_a or negedge rst_a_n)
        if (!rst_a_n) q_a <= 1'b0;
        else          q_a <= d_in_a;

    logic qb_q0, qb_q1;
    always_ff @(posedge clk_b or negedge raw_rst_n) begin
        if (!raw_rst_n) begin
            qb_q0 <= 1'b0;
            qb_q1 <= 1'b0;
        end else begin
            qb_q0 <= d_in_b;
            qb_q1 <= qb_q0;
        end
    end
    assign q_b = qb_q1;

endmodule
```

with `fixtures/RDC-008/bad_reset_port_missed_domain.sdc`:

```tcl
create_clock -name clk_a -period 10.0 [get_ports clk_a]
create_clock -name clk_b -period 7.5 [get_ports clk_b]
set_clock_groups -asynchronous -group {clk_a} -group {clk_b}
set_input_delay -clock clk_a 1.0 [get_ports d_in_a]
set_input_delay -clock clk_b 1.0 [get_ports d_in_b]
```
