---
title: "CDC-016: Opposite-edge stages in a synchronizer chain"
linkTitle: "CDC-016 Opposite-edge stages in a synchronizer chain"
weight: 114
---

**Severity:** error

Adjacent chain stages sample on opposite edges of one clock,
so the earlier stage gets about half a period to resolve
instead of a full one (at 50% duty). MTBF falls exponentially
with resolution time; how far depends on the flop and the data
rate, which icarium does not know, so it reports the shape,
not a number. Sample every stage on the same edge.

## Suppression marks

This rule honors: `(* cdc_sync *)`.

## Failing example

`fixtures/CDC-016/bad_opposite_edge.sv`:

```systemverilog
// CDC-016: stage 1 samples on the positive edge of dst_clk,
// stage 2 on the negative edge. Depth reads 2, but each value
// gets half a period to resolve instead of a full one.
module bad_opposite_edge (
    input  logic src_clk,
    input  logic dst_clk,
    input  logic rst_n,
    input  logic d_in,
    output logic q_out
);

    logic src_q;
    always_ff @(posedge src_clk or negedge rst_n) begin
        if (!rst_n) src_q <= 1'b0;
        else        src_q <= d_in;
    end

    logic sync_1;
    always_ff @(posedge dst_clk or negedge rst_n) begin
        if (!rst_n) sync_1 <= 1'b0;
        else        sync_1 <= src_q;
    end

    logic sync_2;
    always_ff @(negedge dst_clk or negedge rst_n) begin
        if (!rst_n) sync_2 <= 1'b0;
        else        sync_2 <= sync_1;
    end

    assign q_out = sync_2;

endmodule
```

with `fixtures/CDC-016/bad_opposite_edge.sdc`:

```tcl
create_clock -name src_clk -period 10.0 [get_ports src_clk]
create_clock -name dst_clk -period 7.5  [get_ports dst_clk]
set_clock_groups -asynchronous -group {src_clk} -group {dst_clk}
set_input_delay -clock src_clk 1.0 [get_ports d_in]
```
