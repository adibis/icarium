---
title: "CDC-019: Independently-synced one-hot decode across CDC"
linkTitle: CDC-019
weight: 117
---

**Severity:** warning

One comb decoder fans to two or more 1-bit source flops that
cross to the same domain: lanes change together upstream but
resolve apart, so the destination can sample combinations the
encoder never emits. Gray-code the source or handshake it.

## Suppression marks

This rule honors: `(* cdc_gray *)`, `(* cdc_static *)`, `(* cdc_sync *)`.

## Failing example

`fixtures/CDC-019/bad_onehot_decode.sv`:

```systemverilog
// CDC-019: a 2-to-4 one-hot decoder registered lane by lane,
// each lane crossing through its own 2FF. Every lane is 1-bit
// so CDC-004 stays out, but the shared decoder couples them.
module bad_onehot_decode (
    input  logic       src_clk,
    input  logic       dst_clk,
    input  logic [1:0] sel,
    output logic [3:0] sync_out
);

    logic [3:0] one_hot;
    always_comb begin
        one_hot = '0;
        one_hot[sel] = 1'b1;
    end

    logic d0, d1, d2, d3;
    always_ff @(posedge src_clk) begin
        d0 <= one_hot[0];
        d1 <= one_hot[1];
        d2 <= one_hot[2];
        d3 <= one_hot[3];
    end

    logic d0_m, d0_s, d1_m, d1_s, d2_m, d2_s, d3_m, d3_s;
    always_ff @(posedge dst_clk) begin
        d0_m <= d0; d0_s <= d0_m;
        d1_m <= d1; d1_s <= d1_m;
        d2_m <= d2; d2_s <= d2_m;
        d3_m <= d3; d3_s <= d3_m;
    end

    assign sync_out = {d3_s, d2_s, d1_s, d0_s};

endmodule
```

with `fixtures/CDC-019/bad_onehot_decode.sdc`:

```tcl
create_clock -name src_clk -period 10.0 [get_ports src_clk]
create_clock -name dst_clk -period 7.5  [get_ports dst_clk]
set_clock_groups -asynchronous -group {src_clk} -group {dst_clk}
set_input_delay -clock src_clk 1.0 [get_ports sel]
```
