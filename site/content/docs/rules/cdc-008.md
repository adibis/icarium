---
title: "CDC-008: Clock signal used as data"
linkTitle: "CDC-008 Clock signal used as data"
weight: 106
---

**Severity:** error

A bit that drives a flop clock (or an SDC clock port) also feeds
a non-clock input: clocks ride low-skew networks and sampling
them as data breaks STA. Clock-distribution cells, clock pins,
and off-chip forwarding are exempt; the rest is a wiring bug.

## Failing example

`fixtures/CDC-008/bad_clock_as_data.sv`:

```systemverilog
module bad_clock_as_data (
    input  logic clk,
    input  logic d,
    output logic q
);
  logic div_q, dst_q;

  always_ff @(posedge clk) div_q <= ~div_q;
  always_ff @(posedge div_q) dst_q <= div_q & d;
  assign q = dst_q;
endmodule
```

with `fixtures/CDC-008/bad_clock_as_data.sdc`:

```tcl
create_clock -name clk -period 10 [get_ports clk]
set_input_delay -clock clk 1.0 [get_ports d]
```
