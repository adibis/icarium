# CDC-024: Single source fanning to multiple synchronizers

**Severity:** warning

One source bit reaches two or more synchronizer chains: each
chain resolves metastability on its own edge, so the set only
holds when the destinations never recombine what they latched
apart. CDC-005 proves the recombination; this rule flags the
fanout itself for the independence judgement.

## Failing example

`fixtures/CDC-024/bad_fanout.sv`:

```systemverilog
// CDC-024: one source bit fans out to two independent 2FF chains
// in the same foreign domain. The chains never recombine, so
// CDC-005 stays silent; the fanout itself still needs the
// independence judgement.
module bad_fanout (
    input  wire clk_a,
    input  wire clk_b,
    input  wire flag_in,
    output wire flag_a,
    output wire flag_b
);
    reg flag_q;
    always_ff @(posedge clk_a) flag_q <= flag_in;

    reg a1, a2;
    always_ff @(posedge clk_b) a1 <= flag_q;
    always_ff @(posedge clk_b) a2 <= a1;

    reg b1, b2;
    always_ff @(posedge clk_b) b1 <= flag_q;
    always_ff @(posedge clk_b) b2 <= b1;

    assign flag_a = a2;
    assign flag_b = b2;
endmodule
```

with `fixtures/CDC-024/bad_fanout.sdc`:

```tcl
create_clock -name clk_a -period 10.0 [get_ports clk_a]
create_clock -name clk_b -period 7.0  [get_ports clk_b]
set_clock_groups -asynchronous -group {clk_a} -group {clk_b}
set_input_delay -clock clk_a 1.0 [get_ports flag_in]
```
