---
title: "RDC-005: Async reset from multiple independent sources"
linkTitle: RDC-005
weight: 129
---

**Severity:** warning

A flop's async reset combines two or more top-level ports with
no flop behind the gate. Independent board sources release at
independent times; the consumer's release edge is undefined.
Qualify the sources through one reset tree.

## Suppression marks

This rule honors: `(* reset_sync *)`.

## Failing example

`fixtures/RDC-005/bad_multi_source_reset.sv`:

```systemverilog
// RDC-005: two independent board resets ANDed onto one ARST
// pin with no flop behind the gate. The sources release at
// independent times, so the release edge is undefined. RDC-004
// skips port-only comb, which is why this rule exists.
module bad_multi_source_reset (
    input  logic clk,
    input  logic global_rst_n,
    input  logic block_rst_n,
    input  logic d_in,
    output logic q_out
);

    logic combined_rst_n;
    assign combined_rst_n = global_rst_n & block_rst_n;

    always_ff @(posedge clk or negedge combined_rst_n) begin
        if (!combined_rst_n) q_out <= 1'b0;
        else                 q_out <= d_in;
    end

endmodule
```

with `fixtures/RDC-005/bad_multi_source_reset.sdc`:

```tcl
create_clock -name clk -period 10.0 [get_ports clk]
set_input_delay -clock clk 1.0 [get_ports d_in]
```
