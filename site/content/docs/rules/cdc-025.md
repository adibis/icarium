---
title: "CDC-025: Unresolved clock association"
linkTitle: CDC-025
weight: 123
---

**Severity:** warning

A crossing endpoint has no clock association: undriven flop
clock, macro or memory output, unhandled primitive, or an
untyped input the other port rules do not own. One finding
per endpoint names the reason and the fanout; per-pair sync
verdicts on unclocked endpoints would be noise. Type the
source, model the macro, or waive after review.

## Failing example

`fixtures/CDC-025/bad_macro_output.sv`:

```systemverilog
(* blackbox *)
module vendor_filter (
    input  wire sample_in,
    output wire sample_out
);
endmodule

// CDC-025: the macro output feeds a flop but carries no clock
// association; the vendor body is invisible, so the crossing
// cannot prove synchronicity. One finding names the macro.
module bad_macro_output (
    input  wire clk,
    input  wire d_in,
    output wire q
);
    wire macro_data;
    vendor_filter u_filt (
        .sample_in (d_in),
        .sample_out(macro_data)
    );

    reg q_r;
    always_ff @(posedge clk) q_r <= macro_data;
    assign q = q_r;
endmodule
```

with `fixtures/CDC-025/bad_macro_output.sdc`:

```tcl
create_clock -name clk -period 10.0 [get_ports clk]
```
