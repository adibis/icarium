---
title: "CDC-006: Glitchy combinational source on a control crossing"
linkTitle: CDC-006
weight: 105
---

**Severity:** error

A synchronizer first stage traces back through logic alone to
top-level ports, with no registering flop: the chain can sample
a transient no stable input ever held. Register the source in
its own domain before synchronizing it.

## Suppression marks

This rule honors: `(* cdc_sync *)`.

## Failing example

`fixtures/CDC-006/bad_comb_source.sv`:

```systemverilog
module bad_comb_source (
    input  logic ca,
    input  logic cb,
    input  logic p1,
    input  logic p2,
    output logic q
);
  logic s1_q, s2_q;

  always_ff @(posedge cb) s1_q <= p1 & p2;
  always_ff @(posedge cb) s2_q <= s1_q;
  assign q = s2_q;
endmodule
```

with `fixtures/CDC-006/bad_comb_source.sdc`:

```tcl
create_clock -name ca -period 10 [get_ports ca]
create_clock -name cb -period 7 [get_ports cb]
set_clock_groups -asynchronous -group {ca} -group {cb}
set_input_delay -clock ca 1.0 [get_ports p1]
set_input_delay -clock ca 1.0 [get_ports p2]
```

## Passing examples

- `good_same_domain.sv` — clean (same domain)
