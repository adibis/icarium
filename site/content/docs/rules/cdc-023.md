# CDC-023: Clock net driven by a combine of declared clocks

**Severity:** warning

A gate mixes two or more declared clocks onto one net: the net
glitches, runs at no declared frequency, and leaves its flops
domainless. Gate one clock, or mux instead of mixing.

## Failing example

`fixtures/CDC-023/bad_clock_combine.sv`:

```systemverilog
// CDC-023: two declared clocks ANDed onto one net feeding a
// flop clock. The tracer declines instead of picking a leg,
// and the rule names the gate, the net, and the clocks.
module bad_clock_combine (
    input  wire clkA,
    input  wire clkB,
    input  wire d,
    output reg  q
);
  wire gclk = clkA & clkB;
  always @(posedge gclk) q <= d;
endmodule
```

with `fixtures/CDC-023/bad_clock_combine.sdc`:

```tcl
create_clock -name clkA -period 10.0 [get_ports clkA]
create_clock -name clkB -period 7.0  [get_ports clkB]
set_clock_groups -asynchronous -group {clkA} -group {clkB}
set_input_delay -clock clkA 1.0 [get_ports d]
```

More failing cases: `bad_generated_combine.sv`.
