**Severity:** warning

A top input with no set_input_delay clock typing reaches a
flop D or SRST pin: one domain is a methodology warning, two
or more an error no typing can silence. Type the port, then
synchronize the foreign side when the domains disagree.

## Failing example

`fixtures/CDC-011/bad_port_no_sync.sv`:

```systemverilog
module bad_port_no_sync (
    input  logic ca,
    input  logic cb,
    input  logic d,
    output logic q
);
  logic src_q, s1_q, s2_q;

  always_ff @(posedge ca) src_q <= d;
  always_ff @(posedge cb) s1_q <= src_q;
  always_ff @(posedge cb) s2_q <= s1_q;
  assign q = s2_q;
endmodule
```

with `fixtures/CDC-011/bad_port_no_sync.sdc`:

```tcl
create_clock -name ca -period 10 [get_ports ca]
create_clock -name cb -period 7 [get_ports cb]
set_clock_groups -asynchronous -group {ca} -group {cb}
```

More failing cases: `bad_port_srst.sv`, `bad_port_two_domains.sv`.
