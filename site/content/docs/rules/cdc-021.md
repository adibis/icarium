---
title: "CDC-021: Flop clock driven by an undeclared port"
linkTitle: CDC-021
weight: 119
---

**Severity:** error

A top-level input port drives flop clocks with no create_clock
behind it. Undeclared clocks appear in no async group, so every
other check touching the domain silently skips. Declare it.

## Failing example

`fixtures/CDC-021/bad_undeclared_toggle.sv`:

```systemverilog
// CDC-021: a toggle clocked by clk_aux, which no create_clock
// declares. The domain still resolves, but every async-group
// check touching it goes blind. Only CDC-021 names the cause.
module bad_undeclared_toggle (
    input  logic clk_aux,
    output logic q_out
);

    logic q_aux;
    always_ff @(posedge clk_aux) q_aux <= ~q_aux;

    assign q_out = q_aux;

endmodule
```

with `fixtures/CDC-021/bad_undeclared_toggle.sdc`:

```tcl
# SDC intentionally empty: clk_aux is the only top-level input
# and it has no create_clock declaration.
```

## Passing examples

- `good_declared_toggle.sv` — clean (declared toggle)
