---
title: "CDC-012: Gated bus crossing without synced-back handshake"
linkTitle: CDC-012
weight: 110
---

**Severity:** warning

A gated multi-bit crossing has no handshake holding the
payload: the destination latches cycles after the request,
by which time the source may have moved on. Hold the source
payload until a synced-back ack confirms the sample.

## Suppression marks

This rule honors: `(* cdc_gray *)`, `(* cdc_handshake *)`.

## Failing example

`fixtures/CDC-012/bad_one_sided.sv`:

```systemverilog
// CDC-012: the request syncs into dst before gating the capture,
// so the bus looks gated, but the payload advances every src cycle
// while the request is in flight. Nothing holds it stable.
module bad_one_sided (
    input  logic       src_clk,
    input  logic       dst_clk,
    input  logic       rst_n,
    input  logic       src_req,
    input  logic [7:0] src_data,
    output logic [7:0] dst_data
);

    logic [7:0] src_payload;
    logic       src_req_q;
    always_ff @(posedge src_clk or negedge rst_n) begin
        if (!rst_n) begin
            src_payload <= 8'h00;
            src_req_q   <= 1'b0;
        end else begin
            src_payload <= src_data;
            src_req_q   <= src_req;
        end
    end

    logic req_meta;
    logic req_sync;
    always_ff @(posedge dst_clk or negedge rst_n) begin
        if (!rst_n) begin
            req_meta <= 1'b0;
            req_sync <= 1'b0;
        end else begin
            req_meta <= src_req_q;
            req_sync <= req_meta;
        end
    end

    always_ff @(posedge dst_clk or negedge rst_n) begin
        if (!rst_n)        dst_data <= 8'h00;
        else if (req_sync) dst_data <= src_payload;
    end

endmodule
```

with `fixtures/CDC-012/bad_one_sided.sdc`:

```tcl
create_clock -name src_clk -period 4.0  [get_ports src_clk]
create_clock -name dst_clk -period 10.0 [get_ports dst_clk]
set_clock_groups -asynchronous -group {src_clk} -group {dst_clk}
set_input_delay -clock src_clk 0.5 [get_ports src_req]
set_input_delay -clock src_clk 0.5 [get_ports src_data]
```
